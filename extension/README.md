# JustListen Chrome Extension

P0 浏览器扩展工程。当前版本会在 Bilibili 播放器中挂载 JustListen，提供可拖动、可缩放的字幕毛玻璃遮罩和「别看字」书签条入口。

## P0 操作

- 点击右侧书签条：开启或关闭字幕遮罩；
- 拖动遮罩内部：移动遮罩；
- 拖动遮罩边缘或四角：调整大小；
- 遮罩开启时按住书签条：临时显示字幕，松开后恢复；
- 遮罩开关、位置和大小会保存在浏览器本地。

## P1 OCR Test

播放器右侧会显示开发用的「硬字幕 PaddleOCR Test」面板：

- 播放到带硬字幕的位置后点击「开始识别」；
- 面板只扫描视频画面底部 35%，与 P0 遮罩无关；播放器控制栏是页面元素，不会进入视频取帧；
- 使用 PP-OCRv5 检测文字框并识别简中、繁中、英文和日文；
- 最近一次结果会分别显示检测框、识别结果和最终保留数，便于判断问题发生在哪一层；
- 同一字幕连续命中两次才生成一条分句，字幕变化时结束上一句；
- 面板会根据已确认字幕判断当前字幕语言；
- 当前测试不写入持久化存储，也不保存字幕截图，刷新页面即清空；
- 当前测试不打包模型，首次启动时按需加载官方模型，可能需要一些时间。

## 本地运行

```bash
npm install
npm run build
```

然后在 Chrome 中：

1. 打开 `chrome://extensions`；
2. 开启「开发者模式」；
3. 点击「加载已解压的扩展程序」；
4. 选择本目录下生成的 `dist` 文件夹；
5. 打开或刷新一个 Bilibili 视频页面。

## 开发模式

```bash
npm run dev
```

该命令会持续重新构建。代码更新后刷新 Bilibili 页面即可；如果修改了 `manifest.json`，还需要在扩展管理页重新加载扩展。

## 检查

```bash
npm run check
```

该命令依次执行 TypeScript 检查和生产构建。
